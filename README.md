# LingoGo

Phrasebook bahasa daerah untuk wisatawan di Indonesia. Pengguna mencari kota, lalu aplikasi menampilkan bahasa daerah kota itu beserta frasa sehari-hari per kategori. Setiap frasa berisi istilah daerah, cara baca, dan artinya.

Tugas TST × PWAM, kelas K02. API publik: **https://lingogo.stei.site/api**
